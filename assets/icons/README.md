# 图标素材 / Icon assets

导航栏 5 个图标的独立可复用素材,每个提供矢量 `.svg`(可无限缩放)和 512×512 透明 `.png`。

| 文件 | 含义 |
| --- | --- |
| 01-new-chat | 开启新对话 |
| 02-favorite | 我的收藏 |
| 03-library | 能力库 |
| 04-automation | 自动化任务 |
| 05-memory | 我的记忆 |

- 线条色:`#242529`,线宽 1.33333(基于 16×16 视图)。
- SVG 可直接在 Figma / Illustrator / 网页 `<img>` / CSS background 中使用,无外部依赖。
- PNG 为透明底,适合直接贴到任意背景。
